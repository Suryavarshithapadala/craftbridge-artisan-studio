# CraftBridge Artisan Studio

Build a modern, responsive, AI-powered web application called CraftBridge.

Project purpose:
CraftBridge connects traditional Indian artisans with digital opportunities by helping them create professional product catalogues using AI.

Design:

Premium, modern Indian handicraft-inspired design.

Warm terracotta, cream, earthy brown and olive green colours.

Beautiful handmade pottery, textiles, wooden crafts and traditional Indian artwork.

Clean typography, attractive product cards and smooth interactions.

Fully responsive for desktop and mobile.

Main pages:

Home

Explore Crafts

Artisan Registration and Login

Artisan Dashboard

Add Product

AI Product Studio

Craft Story Generator

Telugu-English Translation

Smart Pricing Calculator

Digital Product Catalogue

Core features:

Artisan registration with name, location and preferred language.

Upload handmade product images.

AI-assisted product recognition.

AI-generated product titles, descriptions and keywords.

Telugu and English translation.

AI craft story generation using artisan-provided information.

Pricing calculator based on raw materials, labour, packaging and profit margin.

Save, edit and manage approved products in a digital catalogue.

Create a functional prototype with working navigation, interactive forms, sample products, dashboard and responsive layouts.

Do not make it just a static landing page. Build the actual application experience with separate artisan and customer interfaces.

Use realistic Indian handicraft sample products and make the interface polished enough for a university hackathon demonstration.
